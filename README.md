
# taskbridge-api

Lightweight multi-tenant TaskBridge API built with Node.js, Express, and Prisma.

## Quick start

Prerequisites: Node.js 18+ and PostgreSQL.

Install dependencies:

```bash
npm install
```

Run the app in development:

```bash
npm start
```

Run tests:

```bash
npm test
```

## Repository layout

- `src/` — application source
- `prisma/` — Prisma schema and migrations
- `tests/` — test suite
